# 📖 منارة اللغة العربية (Manaret Al Lougha)
> **نحو مستقبل مبدع** — تطبيق تعليمي مخصص لمادة اللغة العربية للطور المتوسط في الجزائر، تحت إشراف **الأستاذ بن مزوز حمزة**.

---

## 🌟 مميزات التطبيق (Features)

*   **🗂️ تنظيم المحتوى الدراسي:** تقسيم الدروس حسب السنوات الدراسية (الأولى، الثانية، الثالثة، والرابعة متوسط) والفصول الدراسية (الفصل الأول، الثاني، والثالث).
*   **📂 تكامل تام مع Google Drive:** يحتوي كل مقطع دراسي (المقطع الأول، الثاني، والثالث) على زر انتقال مباشر إلى مجلد Google Drive الخاص به لتحميل الملخصات والملفات والمستندات التعليمية.
*   **💬 نظام اشتراك وتواصل عبر WhatsApp:** زر تواصل مباشر وسلس مع الأستاذ للاشتراك بلمسة واحدة، مع رسالة تلقائية مخصصة وواجهة تنبيهات بديلة في حال تعذر فتح التطبيق.
*   **🎨 تصميم راقٍ وجذاب:** واجهات تفاعلية حديثة بألوان متناسقة (أزرق داكن وذهبي) مع حركات انتقالية وتأثيرات بصرية ممتازة.
*   **📱 أيقونة تطبيق مخصصة:** أيقونة رسمية مدمجة مستوحاة من واجهة البداية (Splash Screen) متوافقة مع أنظمة Android و iOS.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

*   **الإطار البرمجي (Framework):** Flutter (Dart)
*   **الخطوط (Typography):** Cairo (Google Fonts)
*   **التأثيرات الحركية (Animations):** `animate_do`
*   **التكامل مع الروابط (URL Launcher):** `url_launcher`
*   **تخزين البيانات المحلي (Local Storage):** `shared_preferences`
*   **إدارة الأيقونات:** `flutter_launcher_icons`

---

## 🚀 تشغيل وتطوير التطبيق (Setup & Execution)

### المتطلبات الأساسية (Prerequisites)
*   تثبيت Flutter SDK (الإصدار 3.11 أو أحدث)
*   تثبيت Android Studio أو VS Code

### خطوات التشغيل (Run Steps)

1.  **تحميل الحزم والاعتمادات:**
    ```bash
    flutter pub get
    ```

2.  **تشغيل التطبيق في بيئة التطوير (Debug Mode):**
    ```bash
    flutter run
    ```

3.  **بناء نسخة التطبيق النهائية (Build APK):**
    ```bash
    flutter build apk --release
    ```
